four physical calls per case-replicate: 216 condition results, 288 API calls.

conclusions. The source case and oracle are not available to that call.

provider configuration before live execution. Mock evidence is named `mock_*`
and must not be interpreted as model-performance evidence.

The live evidence bundle will contain the raw `trials.sqlite`, all physical
trials and paired condition exports, deterministic report, operator receipts,
read-only revalidation, zero-call resume, and `run_manifest.json`.

No API credentials are stored here.
